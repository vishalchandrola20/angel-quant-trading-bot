# 🤖 Angel Quant Bot Commands

Here is a cheat sheet for running the various strategies and tools in this project.

---

## 🛠️ Setup & Installation

Install all required libraries (including new ones like Streamlit & Plotly).
```bash
pip install -r requirements.txt
```

---

## 🚀 ITM Momentum Breakdown Strategy

### 1. Backtesting
Run historical simulations to verify strategy performance.

**NIFTY**
```bash
python -m src.backtest.itm_momentum_bt --start 2024-01-01 --end 2024-01-31 --index NIFTY
```

**SENSEX**
```bash
python -m src.backtest.itm_momentum_bt --start 2024-01-01 --end 2024-01-31 --index SENSEX
```

### 2. Result Analysis
Analyze the CSV files generated by the backtester (Day-wise and Hourly breakdown).

**NIFTY**
```bash
python -m src.backtest.analyze_results --index NIFTY
```

**SENSEX**
```bash
python -m src.backtest.analyze_results --index SENSEX
```

### 3. Live Trading & Simulation
**Note:** Ensure your virtual environment is active (`source .venv/bin/activate`).

**Simulation Mode (Paper Trading)**
*Logs trades without placing real orders.*

*NIFTY*
```bash
python -m src.live.itm_momentum_breakdown --index NIFTY
```

*SENSEX*
```bash
python -m src.live.itm_momentum_breakdown --index SENSEX
```

**Live Mode (Real Money)**
*Places actual orders on Angel One.*

*NIFTY*
```bash
python -m src.live.itm_momentum_breakdown --index NIFTY --live
```

*SENSEX*
```bash
python -m src.live.itm_momentum_breakdown --index SENSEX --live
```

## 🦅 Iron Condor Strategy

### 1. Backtesting
*Note: This assumes a backtest script `src/backtest/iron_condor_bt.py` exists.*
```bash
python -m src.main --task backtest_iron_condor --date 2025-12-30
```

### 2. Live Trading & Simulation

**Simulation Mode**
```bash
python -m src.live.iron_condor_ws --index NIFTY
```

**Live Mode**
